# API JASONBOOK
- `GET /api/health` : état du serveur.
- `GET /api/features` : liste des modules disponibles dans l'interface.
Les fonctions sociales des pages HTML existantes continuent d'utiliser Firebase directement. Les appels d'API métier (authentification sécurisée, modération, upload, notifications push) doivent être finalisés et protégés avant ouverture publique.
